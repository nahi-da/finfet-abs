はじめに

FinFeT（Finding & Fetching Tool for Azure Blob Storage）は、Azure ストレージアカウントの Blob コンテナーにある Blob を検索し、リハイドレートとダウンロードを行う Windows 向けのツールです。

本ツールは、Azure Blob Storage を利用するための非公式のツールです。Microsoft Corporation およびその関連会社が開発・提供するものではなく、Microsoft による提携、承認、後援を受けていません。Microsoft、Azure は、Microsoft グループの企業の商標です。

This is an unofficial tool for Azure Blob Storage. It is not developed, provided, endorsed, or sponsored by Microsoft Corporation or its affiliates. Microsoft and Azure are trademarks of the Microsoft group of companies.

主な機能

  • パスパターン（正規表現と変数）による Blob の検索と、検索結果からの Blob の選択
  • Archive 層の Blob のリハイドレートとダウンロード。「ジョブ」としてキューに登録し、順に実行します（日をまたいで継続できます）
  • ダウンロードした圧縮ファイル（zip・tar・gz・bz2・xz）の展開（任意）
  • 画面幅に応じたレイアウト（タブレット・スマートフォンの画面幅にも対応）と、テーマ（ダーク・ライト）・文字サイズの設定
  • 検索履歴と、検索条件のエクスポート・インポート

対応していないこと

  • Blob のアップロード・削除・上書き（本ツールが行う操作は、読み取りとアクセス層の変更に限られます）
  • Blob コンテナー以外のストレージ（ファイル共有（Azure Files）・テーブル・キュー）
  • Windows 以外での実行

動作環境

  • Windows 11（x64）
  • 同梱の Python （開発版）（別途インストールする必要はありません）
  • 本ツールの版: （開発版）

起動手順

  1. 配布用の ZIP ファイルを展開します（導入と更新）。
  2. finfet-abs.bat をダブルクリックします。既定のブラウザに本ツールの画面が表示されます。
  3. 終了する場合は、画面右上のメニューから [終了] を選択します。画面（ブラウザのタブ）をすべて閉じた場合も、一定時間後に自動的に終了します。

初回の操作手順

  1. 接続ページでサインインするか、アクセスキー・SAS で接続先を追加します。
  2. 検索ページで、接続先とパスパターンを指定し、[検索] をクリックします。
  3. 検索結果で Blob を選択し、[ジョブを作成] をクリックします。
