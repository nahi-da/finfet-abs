プロキシ

既定では、環境変数と Windows の設定のプロキシを自動で使います。設定の「プロキシ」で、使わない・指定するを選べます。[接続を確認] で、プロキシを通して Azure に接続できるかを確かめられます。

ログの場所

  • 通常のモード: %LOCALAPPDATA%\finfet-abs\logs\
  • ポータブルモード: <本ツールのフォルダー>\data\<Windows ユーザー名>\logs\
  • ジョブごとのログ: ジョブの詳細のページの [ログのフォルダーを開く]

ログでは、SAS・アクセスキー・トークンなどの秘密情報を伏せています。設定の「データとログ」で、ログの詳しさを変えられます。

問い合わせのときに添えるもの

  • 本ツールの版（画面の右上のメニューの [このツールについて]）と、Windows の版
  • 操作の手順と、表示された文・エラーコード（エラーの [詳細をコピー] でコピーできます）
  • ログの抜粋

ログやスクリーンショットに、ストレージアカウント名・SAS・アカウントキー・テナントの ID などが含まれていないか確認してから送ってください。
