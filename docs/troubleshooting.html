プロキシ

既定では、環境変数と Windows の設定に指定されたプロキシを自動的に使用します。設定の「プロキシ」で、プロキシを使用しない、または指定したプロキシを使用するよう変更できます。[接続を確認] をクリックすると、プロキシを経由して Azure に接続できるかを確認できます。

ログの場所

  • 通常のモード: %LOCALAPPDATA%\finfet-abs\logs\
  • ポータブルモード: <本ツールのフォルダー>\data\<Windows ユーザー名>\logs\
  • ジョブごとのログ: ジョブの詳細のページの [ログのフォルダーを開く]

ログには、SAS・アクセスキー・トークンなどの秘密情報を出力しません。設定の「データとログ」で、ログの詳細さを変更できます。

問い合わせの際に必要な情報

  • 本ツールの版（画面の右上のメニューの [このツールについて] で確認できます）と、Windows の版
  • 操作の手順と、表示されたメッセージ・エラーコード（エラーの [詳細をコピー] でコピーできます）
  • ログの抜粋

ログやスクリーンショットに、ストレージアカウント名・SAS・アカウントキー・テナントの ID などが含まれていないことを確認してから送付してください。
