導入と更新

ダウンロードとハッシュの確認

  1. インターネットに接続できる環境で、GitHub の Release のページから finfet-abs-<版>-win-x64.zip と SHA256SUMS.txt をダウンロードします。
  2. ZIP の SHA-256 を計算し、SHA256SUMS.txt の値と比べます。 
    certutil -hashfile finfet-abs-<版>-win-x64.zip SHA256
  3. （任意）GitHub CLI で、このリポジトリの GitHub Actions で作られたことを確かめます。 
    gh attestation verify finfet-abs-<版>-win-x64.zip --repo nahi-da/finfet-abs

インターネットに接続できない環境への持ち込み

組織の規程に従って、ZIP を使う PC に運びます。Python やパッケージは ZIP に含まれているため、使う PC での導入はありません。

展開と起動

  1. ZIP のプロパティで [許可する] にチェックを入れてから、任意のフォルダー（例: C:\Tools\finfet-abs）に展開します。
  2. finfet-abs.bat を実行します。

ポータブルモードで使う場合は、起動の前に、展開したフォルダーに空の data フォルダーを作ります。

更新

  1. 新しい版の ZIP を、上の手順で新しいフォルダーに展開します（古いフォルダーに上書きしません）。
  2. 本ツールを終了します。
  3. ポータブルモードの場合は、古いフォルダーの data を新しいフォルダーに移します。
  4. 新しいフォルダーの finfet-abs.bat を起動します。動作を確かめたら、古いフォルダーを削除してかまいません。

pip の使い方

  • 導入済みのパッケージの確認: runtime\pip.bat list、runtime\pip.bat check
  • インターネットに接続できない環境での追加・更新: インターネットに接続できる環境で、Windows x64・Python 3.14 用の wheel を取得して持ち込み、次のように導入します。 
    runtime\pip.bat install --no-index --find-links <wheel のフォルダー> <パッケージ>

パッケージを個別に更新すると、本ツールが確認していない版の組み合わせになります。通常は、新しい版の全部入り版で更新してください。
